# 0002. Base: CrossPoint `develop` at bootstrap

- Status: Accepted
- Date: 2026-11-12

## Context

Three CrossPoint commits could start `main`:

- **`2.0.0`** (`42d58daa`), the latest release. It pins FreeInk SDK `5e94fe7`, on which downloads from GitHub
  release links fail: GitHub's 302 carries a `Content-Security-Policy` line longer than the SDK's 4,096-byte header
  line limit. Updates over Wi-Fi and font downloads are broken on that pin (CrossMono ADR 0015).
- **`5d731041`** (2026-11-06), the base of dcarnicer's `firmware.patch`. It pins SDK `fb7e926`, the base of
  `sdk.patch`, so both patches apply as they are. It lacks the SDK fix too.
- **`develop` head**, fetched on bootstrap day: `3a5bfac3`, 30 commits after `5d731041` and 48 after `2.0.0`. It
  pins SDK `6a208c0`, "skip oversized GitHub CSP response headers", moved there by #4420 (`ddd3b1d8`).

## Options considered

1. **`2.0.0`.** A released base, but OTA and font downloads would not work, and we would move the pin at once.
2. **`5d731041`.** dcarnicer's patches apply without conflicts, but we would start 30 commits and one SDK fix
   behind, and the first sync would bring the conflicts back.
3. **`develop` head** (chosen). The SDK download fix is in, and the drift from `5d731041` is resolved once, in W1,
   while porting the patches.

## Decision

`main` starts at CrossPoint `develop` as fetched on 2026-11-12:

| Item | Value |
|---|---|
| Upstream base | `3a5bfac375c293cb38f7e6e28f7736e7d451ef57` on `develop` (committed 2026-11-11 23:00 UTC, "feat: add a Show File Extensions setting for Browse Files (#4450)") |
| Distance | 30 commits after `5d731041`, 48 after `2.0.0` |
| Upstream version string | `[crosspoint] version = 2.0.0` (`platformio.ini:6-7`); `develop` has not bumped it |
| FreeInk SDK pin | `6a208c0c46cce99bafa334bc4f171f5e558c5195` (2026-11-10), set by `ddd3b1d8` (#4420) |
| Nested submodule | `freeink-sdk/libs/assets/Icons/lucide` at `c81680e0` |

## Consequences

- `firmware.patch` was made at `5d731041` and may conflict with the 30 commits since. W1 ports it hunk by hunk
  and records what it keeps, defers or drops.
- `sdk.patch` was made at `fb7e926`. Our pin is 9 commits later; two of them touch the libraries the patch edits
  (`3c2078b` and `567f448`, both EEGO A4 touch), so the port should apply with little conflict.
- The base is not a release, so `platformio.ini` says `2.0.0` although the code is newer. About and the release
  notes show the base commit, not that string ([ADR 0005](0005-versioning-releases-and-updates.md)).
- The next sync merges the next CrossPoint release tag ([docs/upstream-sync.md](../upstream-sync.md)).
